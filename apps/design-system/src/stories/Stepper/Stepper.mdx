다단계 작업의 진행 상태를 시각화하는 컴포넌트입니다. 수평·수직 방향을 지원하며 `Stepper.Step` · `Stepper.Connector` · `Stepper.Content` · `Stepper.Controls` 의 compound 패턴으로 구성합니다.

<Source code={`import Stepper from '@port/design-system'`} language="tsx" />

## API

### Stepper

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `position` | `'horizontal' \| 'vertical'` | `'horizontal'` | 스텝 배치 방향 |
| `showNumbers` | `boolean` | `true` | 스텝 아이콘에 번호 표시 여부 |
| `children` | `ReactNode` | — | Stepper.Step, Stepper.Connector 등을 children으로 전달합니다. |

### Stepper.Step

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `id` | `string \| number` | — | 스텝 식별자 |
| `title` | `string` | — | 스텝 제목 |
| `description` | `string` | — | 스텝 부가 설명 (선택) |
| `stepNumber` | `number` | — | 표시할 순서 번호 (0-based) |
| `isActive` | `boolean` | — | 현재 활성 스텝 |
| `isCompleted` | `boolean` | — | 완료된 스텝 — 체크 아이콘 표시 |
| `isError` | `boolean` | — | 오류 상태 — X 아이콘 표시 |
| `isDisabled` | `boolean` | — | 비활성화 상태 |
| `isOptional` | `boolean` | — | (Optional) 표시 |
| `isClickable` | `boolean` | — | 클릭 가능 여부 |
| `onClick` | `() => void` | — | 스텝 클릭 핸들러 |

### Stepper.Connector

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `isCompleted` | `boolean` | — | 완료된 구간 — 강조 선 표시 |

### Stepper.Controls

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `onPrevious / onNext / onComplete` | `() => void` | — | 이전·다음·완료 버튼 핸들러 |
| `previousButtonText / nextButtonText / completeButtonText` | `string` | `'Previous' / 'Next' / 'Complete'` | 버튼 레이블 |
| `showPrevious / showNext / showComplete` | `boolean` | `true` | 버튼 표시 여부 |
| `isPreviousDisabled / isNextDisabled / isCompleteDisabled` | `boolean` | — | 버튼 비활성화 여부 |
