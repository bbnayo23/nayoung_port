단일 선택을 위한 라디오 버튼 컴포넌트입니다. 같은 `name`을 가진 Radio를 그룹으로 묶어 사용하며, `checked`·`onChange`로 완전 제어(controlled) 방식으로 동작합니다.

<Source code={`import Radio from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `string` | — | 이 라디오 버튼의 값 (required) |
| `name` | `string` | — | 라디오 그룹 이름 — 같은 name끼리 단일 선택됩니다. (required) |
| `label` | `ReactNode` | — | 라벨 텍스트 또는 노드 |
| `checked` | `boolean` | — | 선택 상태 (controlled) |
| `onChange` | `(e: ChangeEvent<HTMLInputElement>) => void` | — | 변경 이벤트 핸들러 |
| `disabled` | `boolean` | `false` | 비활성화 상태 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 크기 |
| `variant` | `'default' \| 'primary'` | `'default'` | 색상 variant |
| `id` | `string` | — | 커스텀 ID. 미지정 시 name+value 조합으로 자동 생성. |
