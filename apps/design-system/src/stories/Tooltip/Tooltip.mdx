`react-popper` 기반의 툴팁 컴포넌트입니다. 8방향 `placement`와 controlled 모드, portal 렌더링을 지원합니다.

<Source code={`import { Tooltip } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `content` | `ReactNode` | — | 툴팁에 표시할 내용 (필수) |
| `children` | `ReactNode` | — | 툴팁 트리거가 될 요소 (필수) |
| `placement` | `Placement` | `'top'` | 툴팁 위치 — top · bottom · left · right 및 -start · -end 변형 포함 (총 12방향) |
| `open` | `boolean` | — | Controlled 모드 — 툴팁 표시 여부를 외부에서 제어합니다. |
| `onOpen` | `() => void` | — | Controlled 모드에서 마우스 진입 시 호출 |
| `onClose` | `() => void` | — | Controlled 모드에서 마우스 이탈 시 호출 |
| `portal` | `boolean` | `false` | true면 document.body에 포털 렌더링 — overflow:hidden 부모에서도 잘리지 않습니다. |
| `portalTarget` | `HTMLElement \| () => HTMLElement` | — | portal=true 시 렌더링 대상 엘리먼트. 미지정 시 document.body |
| `popperOptions` | `Partial<Options>` | — | usePopper에 전달할 추가 옵션 |
