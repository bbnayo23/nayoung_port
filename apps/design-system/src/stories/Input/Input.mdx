<Subtitle>텍스트 입력 컴포넌트</Subtitle>

텍스트 입력 컴포넌트입니다. 5가지 `variant`, 3가지 `size`, 접두/접미 아이콘(`prefixIcon` · `suffixIcon`), 클리어 버튼, 도움말 텍스트를 지원합니다.

`value`, `onChange`, `type`, `readOnly`, `maxLength` 등 표준 `InputHTMLAttributes` 속성을 모두 전달할 수 있습니다. 단, HTML `size` 속성은 컴포넌트의 `size` prop이 우선합니다.

<Source code={`import Input from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'ghost' \| 'error' \| 'success' \| 'warning'` | `'default'` | 시각적 상태 변형 — 테두리 색상과 helperText 색상에 반영됨 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 입력 필드 높이 및 폰트 크기 |
| `fullWidth` | `boolean` | `true` | 컨테이너 너비 100% 사용. false이면 내용에 맞춤 |
| `prefixIcon` | `ReactNode` | — | 입력 왼쪽에 표시할 요소 (아이콘, 텍스트 등) |
| `suffixIcon` | `ReactNode` | — | 입력 오른쪽에 표시할 요소. 지정 시 showClearButton 무시 |
| `showClearButton` | `boolean` | `false` | 클리어(×) 버튼 표시 여부. suffixIcon이 있으면 무시됨 |
| `onClear` | `() => void` | — | 클리어 버튼 클릭 콜백. showClearButton이 true일 때 필수 |
| `helperText` | `string` | — | 입력 하단 도움말/오류 텍스트. variant 색상으로 표시됨 |
| `disabled` | `boolean` | `false` | 비활성화 상태 |
| `placeholder` | `string` | — | 플레이스홀더 텍스트 |
