## API — Card

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `variant` | `'default' \| 'section' \| 'old-exd' \| 'neo'` | `'default'` | 카드 스타일 변형 |
| `title` | `ReactNode` | — | 카드 헤더 제목 — variant별 헤더 슬롯에 렌더링 |
| `action` | `ReactNode` | — | 헤더 우측 액션 영역 (버튼, 뱃지 등) |
| `size` | `'sm' \| 'md' \| 'lg'` | — | 카드 너비 고정 크기 (280 · 360 · 480px) |
| `density` | `'default' \| 'compact'` | `'default'` | 내부 밀도. compact는 패딩·폰트를 줄여 목록형 카드에 적합 |
| `isActive` | `boolean` | — | 활성 상태 — primary 보더 강조 |
| `disabled` | `boolean` | `false` | 비활성화 — opacity 처리, 클릭 불가 |
| `hoverable` | `boolean` | — | 호버 효과. onClick이 있으면 기본값 true |
| `noPadding` | `boolean` | `false` | 내부 패딩 제거 — 툴바·그리드 등 자체 패딩 컨텐츠에 사용 |
| `onClick` | `(e: MouseEvent) => void` | — | 클릭 핸들러. 설정 시 hoverable 자동 활성화 |
