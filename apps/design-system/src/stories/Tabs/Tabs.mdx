<Subtitle>4가지 variant와 3가지 size를 지원하는 컴파운드 탭 컴포넌트</Subtitle>

`Tabs.List` · `Tabs.Tab` · `Tabs.Contents` 컴파운드 패턴으로 구성되며, 키보드 접근성(← → ↑ ↓ Home End)을 내장합니다. `value`와 `onChange`로 활성 탭을 제어하는 controlled 컴포넌트입니다.

<Source code={`import Tabs from '@port/design-system'`} language="tsx" />

## API

### Tabs

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `string \| number` | — | 현재 활성 탭 값 (controlled) |
| `onChange` | `(value: string \| number) => void` | — | 탭 변경 콜백 |
| `variant` | `'underline' \| 'outline' \| 'enclosed' \| 'fill'` | `'underline'` | 탭 스타일 변형 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 탭 크기 |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 탭 배치 방향 |

### Tabs.Tab

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `string` | — | 탭 고유 값 — Tabs.value와 매칭됩니다. |
| `disabled` | `boolean` | `false` | 비활성 탭. 키보드 이동 시 건너뜁니다. |
| `icon` | `ReactNode` | — | 탭 좌측 아이콘 |

### Tabs.Contents

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `string \| number` | — | 대응하는 Tabs.Tab의 value와 일치해야 합니다. |
| `renderMode` | `'multiRender' \| 'singleRender'` | `'multiRender'` | multiRender: 모두 렌더 후 CSS hidden 제어. singleRender: 활성 탭만 마운트. |
