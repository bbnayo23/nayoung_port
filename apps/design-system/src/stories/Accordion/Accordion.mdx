논리적으로 연관된 여러 섹션을 그룹으로 묶어 관리하는 컴포넌트입니다. `Accordion.Item` · `Accordion.Header` · `Accordion.Content` 컴파운드 패턴으로 구성되며, 그룹 전체의 `iconDirection` · `disabled`를 한 번에 제어할 수 있습니다. 단일 섹션 토글이 필요할 때는 Collapse를 사용하세요.

<Source code={`import { Accordion } from '@port/design-system'`} language="tsx" />

## API

### Accordion

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `iconDirection` | `'left' \| 'right'` | `'right'` | 모든 항목에 공통 적용되는 아이콘 방향 |
| `disabled` | `boolean` | `false` | 그룹 전체 비활성화. 개별 항목보다 우선합니다. |
| `className` | `string` | — | 루트 요소에 추가할 CSS 클래스 |

### Accordion.Item

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | 펼침 상태. 호출자가 직접 제어합니다 (controlled). |
| `onChange` (required) | `(open: boolean) => void` | — | 헤더 클릭 시 다음 열림 상태를 전달하는 콜백 |
| `disabled` | `boolean` | `false` | 해당 항목만 비활성화. Accordion.disabled보다 세밀합니다. |
| `className` | `string` | — | 항목 래퍼 요소에 추가할 CSS 클래스 |

`Accordion.Header`와 `Accordion.Content`는 별도 props 없이 `children`과 표준 HTML 속성(`className` 포함)을 그대로 전달합니다.
