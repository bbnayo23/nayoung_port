검색 입력 컴포넌트입니다. 제어(controlled) · 비제어(uncontrolled) 모드를 모두 지원하며, `prefix` · `leftActions` · `suffixActions` · `rightActions` 등 다양한 슬롯으로 확장 가능합니다. `expandable` 모드에서는 textarea로 전환됩니다.

<Source code={`import { SearchBar } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `string` | — | 제어 모드 값. 미지정 시 uncontrolled. |
| `defaultValue` | `string` | `''` | 비제어 모드 초기값 |
| `onChange` | `(value: string) => void` | — | 입력 변경 콜백 — 문자열 값을 직접 전달합니다. |
| `onSearch` | `(value: string) => void` | — | 검색 실행 콜백 (검색 버튼 클릭 또는 Enter) |
| `onClear` | `() => void` | — | X 버튼 클릭 시 콜백 |
| `placeholder` | `string` | `'검색어를 입력하세요'` | 입력 필드 플레이스홀더 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 크기 variant |
| `disabled` | `boolean` | `false` | 전체 비활성화 |
| `hideButton` | `boolean` | `false` | 검색 버튼 숨김 여부 |
| `searchLabel` | `string` | — | 검색 버튼 aria-label 및 아이콘 옆 표시 텍스트 |
| `expandable` | `boolean` | `false` | 확장 버튼 표시. 클릭 시 textarea 모드로 전환. |
| `expanded` | `boolean` | — | 확장 상태 제어 (controlled). 미지정 시 내부 상태 사용. |
| `onExpandChange` | `(expanded: boolean) => void` | — | 확장 상태 변경 콜백 |
| `prefix` | `ReactNode` | — | 입력 앞 슬롯 (예: AI 배지) |
| `onPrefixClick` | `() => void` | — | prefix 클릭 콜백. 지정 시 prefix가 button으로 렌더. |
| `leftOuterActions` | `ReactNode` | — | SearchBar 외부 왼쪽 슬롯 (예: + 추가 버튼) |
| `leftActions` | `ReactNode` | — | 입력 내부 왼쪽 슬롯 (예: 검색 태그) |
| `suffixActions` | `ReactNode` | — | 검색 버튼 앞 슬롯 (예: 정렬/필터 아이콘) |
| `rightActions` | `ReactNode` | — | SearchBar 외부 오른쪽 슬롯 (예: 일시정지 버튼) |

## 기본 검색

value · onChange · onSearch 조합으로 동작합니다. Enter 키 또는 검색 버튼 클릭 시 onSearch가 호출됩니다.

## 확장 모드 (Expandable)

`expandable` prop을 추가하면 확장 버튼이 나타납니다. 클릭 시 textarea로 전환되어 복잡한 쿼리를 입력할 수 있습니다.
