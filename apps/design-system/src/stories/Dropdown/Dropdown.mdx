단일/다중 선택 드롭다운 컴포넌트입니다. `multiSelect` prop으로 모드를 전환하며, 다중 선택 시 `multiDisplayMode`로 count·values·tags·tags-closable 표시 방식을 선택합니다.

<Source code={`import { Dropdown } from '@port/design-system'
import type { DropdownOption } from '@port/design-system'`} language="tsx" />

## API

### Dropdown (공통)

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `options` | `DropdownOption[]` | — | 선택 옵션 목록 (required) |
| `placeholder` | `string` | `'선택'` | 미선택 상태 텍스트 |
| `label` | `string` | — | 트리거 앞에 통합 표시되는 라벨 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 드롭다운 크기 |
| `disabled` | `boolean` | `false` | 비활성 상태 |
| `width` | `number \| string` | — | 드롭다운 너비 직접 지정 (예: 200, '100%') |
| `forceOpen` | `boolean` | `false` | 메뉴를 강제로 열어둠 (Style Guide 전용) |

### Single Select (기본)

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `multiSelect` | `false` | `false` | 단일 선택 모드 (기본값) |
| `value` | `string` | — | 제어 모드 선택값 |
| `defaultValue` | `string` | — | 비제어 모드 초기값 |
| `onChange` | `(value: string, option: DropdownOption) => void` | — | 값 변경 콜백 |

### Multi Select

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `multiSelect` | `true` | — | 다중 선택 모드 활성화 (required) |
| `multiDisplayMode` | `'count' \| 'values' \| 'tags' \| 'tags-closable'` | `'count'` | 트리거 표시 방식 |
| `value` | `string[]` | — | 제어 모드 선택값 배열 |
| `defaultValue` | `string[]` | — | 비제어 모드 초기값 배열 |
| `onChange` | `(values: string[], options: DropdownOption[]) => void` | — | 값 변경 콜백 |

### DropdownOption

<Source code={`interface DropdownOption {
  value: string
  label: string
  disabled?: boolean  // 개별 옵션 비활성화
  variant?: string    // 태그 모드에서 Badge 색상 (예: 'red', 'green', 'yellow', 'orange', 'purple')
}`} language="tsx" />
