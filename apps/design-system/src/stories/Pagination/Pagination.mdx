## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `totalPages` | `number` | — | 총 페이지 수 (required) |
| `currentPage` | `number` | — | 현재 활성 페이지 번호 (required) |
| `onPageChange` | `(page: number) => void` | — | 페이지 변경 콜백 (required) |
| `maxDisplay` | `number` | `5` | 한 번에 표시할 페이지 버튼 수 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 크기 variant |
| `disabled` | `boolean` | `false` | 전체 비활성화 |
| `showFirstLast` | `boolean` | `false` | 첫/마지막 페이지 이동 버튼 표시 |
| `showPrevNext` | `boolean` | `true` | 이전/다음 버튼 표시 |
| `showPageInfo` | `boolean` | `false` | 현재 페이지 / 전체 페이지 정보 텍스트 표시 |
| `showPageJump` | `boolean` | `false` | 페이지 직접 입력 input 표시 |
| `showItemsPerPage` | `boolean` | `false` | 페이지당 항목 수 드롭다운 표시 |
| `totalItems` | `number` | — | 전체 항목 수 — showPageInfo와 함께 사용 |
| `itemsPerPage` | `number` | — | 현재 페이지당 항목 수 |
| `itemsPerPageOptions` | `number[]` | — | 페이지당 항목 수 선택 목록 (예: [50, 100, 200]) |
| `onItemsPerPageChange` | `(n: number) => void` | — | 페이지당 항목 수 변경 콜백 |
