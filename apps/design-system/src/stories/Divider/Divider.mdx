수평 또는 수직 방향의 구분선 컴포넌트입니다. 두께(`size`), 여백(`margin`), 투명도(`opacity`), 색상(`color`)을 조절할 수 있습니다.

<Source code={`import Divider from "@port/design-system"`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `direction` | `'horizontal' \| 'vertical'` | `'horizontal'` | 구분선 방향 |
| `size` | `number` | `1` | 선 두께 (px). horizontal이면 borderTopWidth, vertical이면 borderLeftWidth에 적용 |
| `margin` | `number` | `0` | 상하(horizontal) 또는 좌우(vertical) 여백 (px) |
| `opacity` | `number` | `1` | 투명도 (0–1). 미지정 시 요소의 기본 opacity 사용 |
| `color` | `string` | — | 선 색상 (CSS color 값). 미지정 시 토큰 색상 사용 |
| `className` | `string` | — | 루트 hr 요소에 추가할 CSS 클래스 |
| `style` | `CSSProperties` | — | 루트 hr 요소 인라인 스타일 (토큰 외 동적 값에만 사용) |

## 두께 (size)

`size` prop으로 선 두께를 조절합니다. horizontal이면 borderTopWidth, vertical이면 borderLeftWidth에 적용됩니다.

## 투명도 (opacity)

`opacity` prop으로 선의 투명도를 조절합니다. 낮은 opacity로 서브 섹션의 위계를 표현할 수 있습니다.
