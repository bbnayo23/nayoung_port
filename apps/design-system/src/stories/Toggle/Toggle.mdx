controlled / uncontrolled 모드를 모두 지원하는 스위치 컴포넌트입니다. `label`과 `innerLabel` 옵션으로 다양한 레이아웃을 구성할 수 있으며 키보드 접근성을 내장합니다.

<Source code={`import { Toggle } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `checked` | `boolean` | — | Controlled 모드 — 외부에서 on/off 상태를 제어합니다. |
| `defaultChecked` | `boolean` | `false` | Uncontrolled 모드 초기값 |
| `onChange` | `(checked: boolean) => void` | — | 상태 변경 콜백 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 트랙 크기 — sm(28×16) · md(40×22) · lg(52×28) |
| `disabled` | `boolean` | `false` | 비활성화. 클릭과 키보드 조작을 막습니다. |
| `label` | `ReactNode` | — | 트랙 오른쪽에 표시되는 라벨 |
| `innerLabel` | `boolean` | `false` | 트랙 내부에 ON/OFF 텍스트를 표시합니다. |
