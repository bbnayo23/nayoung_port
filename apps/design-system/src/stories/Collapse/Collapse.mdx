## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `variant` | `'card' \| 'row' \| 'more' \| 'horizontal'` | `'card'` | 스타일 변형 |
| `header` | `ReactNode` | — | 헤더 영역 (클릭 시 토글). 생략하면 외부 open 제어만 가능 |
| `defaultOpen` | `boolean` | `false` | 초기 열림 상태 (uncontrolled) |
| `open` | `boolean` | — | 제어 모드 열림 상태. onOpenChange와 함께 사용 |
| `onOpenChange` | `(open: boolean) => void` | — | 열림 상태 변경 콜백 |
| `children` | `ReactNode` | — | 펼쳐지는 콘텐츠 영역 |
