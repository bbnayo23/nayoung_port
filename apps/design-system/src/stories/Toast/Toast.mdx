<Subtitle>4가지 variant 를 지원하는 알림 컴포넌트</Subtitle>

`Toast` 는 단독 렌더 또는 `Toaster` + `toast()` 조합으로 스태킹 알림을 구현할 수 있는 알림 컴포넌트입니다. `success` · `error` · `info` · `warning` 네 가지 variant 가 아이콘과 프로그레스바 색상을 결정합니다.

<Source code={`import Toast, { Toaster, toast } from '@port/design-system'`} language="tsx" />

## API

### Toast

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `variant` | `'success' \| 'error' \| 'info' \| 'warning'` | `'success'` | 아이콘과 프로그레스바 색상을 결정합니다. |
| `title` | `string` | — | 토스트 제목 |
| `message` | `string` | — | 토스트 본문 메시지 |
| `duration` | `number` | `3000` | 자동 닫힘 시간(ms). 0이면 자동으로 닫히지 않습니다. |
| `showCloseButton` | `boolean` | `true` | 우측 닫기(×) 버튼 표시 여부 |
| `onClose` | `() => void` | — | 닫기 버튼 클릭 및 duration 만료 시 콜백 |
| `action` | `ReactNode` | — | 우측 액션 버튼 슬롯 |
| `icon` | `ReactNode` | — | 커스텀 아이콘 — 지정 시 variant 기본 아이콘을 대체합니다. |
| `position` | `ToastPosition` | — | 단독 사용 시 위치 진입 애니메이션 클래스 적용 (Toaster 사용 시 생략) |
| `isClosing` | `boolean` | — | 퇴장 애니메이션 상태 (토스트 매니저 연동 시 사용) |

### Toaster

앱 루트에 한 번 배치합니다. sonner 의 `Toaster` props 를 모두 전달할 수 있습니다.

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `position` | `ToastPosition` | `'top-right'` | 스택 위치 |
| `...rest` | `SonnerToasterProps` | — | sonner Toaster 의 모든 props 전달 가능 |

### toast() helper
