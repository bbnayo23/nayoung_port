<Subtitle>트리거 요소 주변에 부유하는 콘텐츠 패널</Subtitle>

트리거 요소 주변에 부유하는 콘텐츠 패널입니다. `visible`·`onVisibleChange`로 완전 제어(controlled)하며, Popper.js 기반 위치 계산으로 화면 경계를 자동 처리합니다.

<Source code={`import { Popover } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 팝오버를 여는 트리거 요소 (required) |
| `content` | `ReactNode` | — | 팝오버 본문 콘텐츠 (required) |
| `visible` | `boolean` | — | 팝오버 표시 여부 (controlled, required) |
| `onVisibleChange` | `(visible: boolean) => void` | — | 표시 상태 변경 콜백 |
| `placement` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | 팝오버 표시 방향. 공간 부족 시 자동 반전됩니다. |
| `title` | `ReactNode` | — | 팝오버 제목. 지정 시 본문 위에 렌더됩니다. |
| `arrow` | `boolean` | `false` | 화살표 표시 여부 |
| `closeButton` | `boolean` | `false` | 우측 상단 닫기(×) 버튼 표시 여부 |
| `disabled` | `boolean` | `false` | 비활성화 — 팝오버가 렌더되지 않습니다. |
| `offset` | `[number, number]` | `[0, 8]` | 트리거와 팝오버 사이 오프셋 [skid, distance] |
| `portal` | `boolean` | `true` | Portal로 렌더 여부. false면 DOM 인라인 렌더. |
| `closeOnOutsideClick` | `boolean` | `true` | 팝오버 외부 클릭 시 닫기 |
| `onClick` | `() => void` | — | 트리거 클릭 핸들러 |
