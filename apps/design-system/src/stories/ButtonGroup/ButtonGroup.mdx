여러 선택지 중 하나를 선택하는 토글 버튼 그룹 컴포넌트입니다. `primary`(슬라이더 탭)와 `secondary`(토글 버튼) 두 가지 variant를 지원합니다.

<Source code={`import ButtonGroup from '@port/design-system'`} language="tsx" />

## API

### ButtonGroup

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | 버튼 그룹 스타일 — primary는 슬라이더 탭, secondary는 토글 버튼 |
| `children` | `ReactNode` | — | ButtonGroup.Item 컴포넌트들 |
| `className` | `string` | — | 래퍼 요소에 추가할 CSS 클래스 |

### ButtonGroup.Item

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | 활성화 상태. 선택된 항목임을 시각적으로 표시합니다. |
| `disabled` | `boolean` | `false` | 비활성화 상태 — opacity, pointer-events 비활성 |
| `onClick` | `() => void` | — | 클릭 핸들러 |
| `children` | `ReactNode` | — | 버튼 레이블 또는 아이콘 |
