<Subtitle>데이터를 행·열로 표시하는 compound 테이블 컴포넌트</Subtitle>

데이터를 행·열로 표시하는 테이블 컴포넌트입니다. `Table.Head` · `Table.Body` · `Table.Row` · `Table.Cell` · `Table.HeaderCell` 의 compound 패턴으로 구성합니다. 정렬, 행 확장, striped, hoverable 등을 지원합니다.

<Source code={`import Table from '@port/design-system'`} language="tsx" />

## API

### Table

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 행 높이 및 폰트 크기 |
| `striped` | `boolean` | — | 짝수 행에 배경색을 적용해 줄무늬 효과 |
| `hoverable` | `boolean` | — | 행 hover 시 배경 하이라이트 |
| `bordered` | `boolean` | — | 셀 테두리 전체 표시 |
| `toolbarExtra` | `ReactNode` | — | 테이블 상단 툴바 영역에 추가할 컨텐츠 |

### Table.Row

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `expandable` | `boolean` | — | 행 확장 가능 여부 — 좌측 토글 아이콘 표시 |
| `expanded` | `boolean` | — | 현재 확장 상태 (controlled) |
| `onExpandToggle` | `(expanded: boolean) => void` | — | 확장 토글 핸들러 |
| `active` | `boolean` | — | 행 선택/활성 상태 강조 |

### Table.HeaderCell

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `sortable` | `boolean` | — | 정렬 가능 열 — 클릭 시 정렬 아이콘 표시 |
| `sortDirection` | `'asc' \| 'desc' \| null` | — | 현재 정렬 방향 (controlled) |
| `onSort` | `() => void` | — | 정렬 클릭 핸들러 |
| `align` | `'left' \| 'center' \| 'right'` | `'left'` | 텍스트 정렬 |

### Table.Cell

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `align` | `'left' \| 'center' \| 'right'` | `'left'` | 텍스트 정렬 |
