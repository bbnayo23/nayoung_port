<Subtitle>집계 수치를 가로로 나열하는 통계 바</Subtitle>

보안 이벤트·알림 등의 집계 수치를 가로로 나열하는 통계 바입니다. 합계 항목과 개별 항목을 구분하고, hover 시 `popoverContent`로 상세 정보를 표시할 수 있습니다.

<Source code={`import { StatsBar, StatItem, StatCount, StatLabel } from '@port/design-system'`} language="tsx" />

## API

### StatsBar

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | StatItem 컴포넌트들을 children으로 전달합니다. |

### StatItem

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `$isTotal` | `boolean` | — | 합계 항목임을 나타냅니다. 시각적으로 강조 표시됩니다. |
| `$active` | `boolean` | — | 선택된 항목 상태. 배경색으로 활성 상태를 표시합니다. |
| `popoverContent` | `ReactNode` | — | hover 시 표시할 Popover 콘텐츠. 미설정 시 Popover 비활성. |
| `children` | `ReactNode` | — | StatCount + StatLabel 조합을 children으로 전달합니다. |

### StatCount

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `$isTotal` | `boolean` | — | 합계 항목의 카운트. 일반 항목보다 큰 폰트로 표시됩니다. |
| `children` | `ReactNode` | — | 표시할 숫자 또는 텍스트. |

### StatLabel

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | 항목 이름 레이블. |
