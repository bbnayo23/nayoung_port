<Source
  code={`import {
  PageContent, PageHeaderRow, SectionCard, GridContainer,
  PaginationBar, SectionToolbar, ToolbarLeft, ToolbarCenter,
  ToolbarRight, TotalCount, IconButton, GhostIconButton,
} from '@port/design-system'`}
  language="tsx"
/>

## 컴포넌트 목록

| 컴포넌트 | Type | Props | 설명 |
| --- | --- | --- | --- |
| `PageContent` | `div` | — | 페이지 최상위 컨테이너. 전체 여백과 배경을 설정합니다. |
| `PageHeaderRow` | `div` | — | 페이지 제목과 상단 액션 영역의 행 레이아웃입니다. |
| `SectionCard` | `div` | `$flex?: boolean` | 섹션 카드. $flex prop으로 flex 레이아웃으로 전환할 수 있습니다. |
| `GridContainer` | `div` | — | 테이블/그리드가 배치되는 컨테이너입니다. |
| `PaginationBar` | `div` | — | 페이지네이션 영역. SectionCard 하단에 위치합니다. |
| `SectionToolbar` | `div` | — | 툴바 행. ToolbarLeft/Center/Right를 자식으로 받습니다. |
| `ToolbarLeft` | `div` | — | 툴바 왼쪽 영역 (TotalCount, 필터 등). |
| `ToolbarCenter` | `div` | — | 툴바 중앙 영역. |
| `ToolbarRight` | `div` | — | 툴바 오른쪽 영역 (IconButton 등). |
| `TotalCount` | `span` | — | 총 건수 표시 텍스트 컴포넌트입니다. |
| `IconButton` | `button` | — | 툴바용 아이콘 버튼 (기본 배경 있음). |
| `GhostIconButton` | `button` | — | 툴바용 고스트 아이콘 버튼 (배경 없음). |
