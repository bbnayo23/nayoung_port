<Subtitle>XDR 테마용 좌측 사이드 네비게이션 바</Subtitle>

XDR 테마에서 사용하는 좌측 사이드 네비게이션 바입니다. 접기/펼치기, 다단계 서브메뉴, hover 확장, 배지 알림, 그룹 레이블을 지원합니다. `collapsed` 상태는 `localStorage`에 자동으로 저장됩니다.

<Source code={`import SideMenuBar from '@port/design-system'
import type { MenuItem, SideMenuBarProps } from '@port/design-system'`} language="tsx" />

## API — SideMenuBar

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `menuGroup` | `MenuItem[]` | — | 메뉴 항목 배열. MenuItem 타입 참조 (required) |
| `activeKey` | `string` | — | 현재 활성화된 메뉴 아이템의 key (required) |
| `onActiveChange` | `(key: string) => void` | — | 활성 메뉴 변경 콜백 |
| `collapsed` | `boolean` | `true` | 사이드바 접힘 상태 (controlled) |
| `onCollapse` | `(collapsed: boolean) => void` | — | 접기/펼치기 상태 변경 콜백 |
| `header` | `ReactNode` | — | 헤더 영역 — 로고, 브랜드명 등 |
| `footer` | `ReactNode` | — | 하단 고정 영역 — 버전 정보, 프로필 등 |
| `showCollapseButton` | `boolean` | `true` | 헤더 접기/펼치기 버튼 표시 여부 |
| `position` | `'left' \| 'right'` | `'left'` | 사이드바 위치 |

## API — MenuItem

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `key` | `string` | — | 메뉴 아이템의 고유 키 (required) |
| `label` | `string` | — | 메뉴 텍스트 (required) |
| `type` | `'item' \| 'group'` | `'item'` | `'group'`으로 설정하면 클릭 불가한 섹션 레이블로 렌더됩니다 |
| `icon` | `ReactNode` | — | 메뉴 아이콘 (@port/icon-library 사용 권장) |
| `children` | `MenuItem[]` | — | 서브 메뉴 배열 — 재귀 지원 |
| `badge` | `number` | — | 알림 배지 숫자. 99 초과 시 "99+"로 클램핑 |
| `tooltip` | `string` | — | 접힌 상태에서 표시할 툴팁. 미지정 시 label 사용 |
| `url` | `string` | — | 링크 URL |
| `target` | `'_blank' \| '_self' \| '_parent' \| '_top'` | — | `'_blank'`이면 외부링크 아이콘이 표시됩니다 |
| `showDivider` | `boolean` | `false` | 항목 아래 구분선 표시 |
| `onClick` | `(e: MouseEvent) => void` | — | 클릭 핸들러 |

## 배지 알림

`badge` prop에 숫자를 전달합니다. 99 초과 시 "99+"로 표시되고, 0이면 배지가 숨겨집니다.

<Canvas of={Stories.WithBadge} />

## 그룹 레이블

`type: 'group'` 항목으로 메뉴를 섹션별로 구분합니다. 접힌 상태에서는 레이블이 자동으로 숨겨집니다.

<Canvas of={Stories.WithGroupLabel} />

## 접힘 상태 (Collapsed)

접힌 상태(56px)로 시작합니다. 헤더 토글 버튼 또는 메뉴 본문 hover로 일시 확장되며, 마우스가 벗어나면 다시 접힙니다. 접힘 상태는 `igloo-side-menu-bar-collapsed` 키로 `localStorage`에 자동 저장되고, `getStoredCollapsed()` 헬퍼로 초기값을 읽어올 수 있습니다.
