## API — GnbProps

### 좌측 브랜드

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `logo` | `ReactNode` | AiR Works 로고 | 좌측 로고 마크 |
| `title` | `string` | `'AiR Works'` | 브랜드 타이틀 |
| `showBrandDropdown` | `boolean` | `true` | 드롭다운 셰브론 표시 |
| `onBrandClick` | `() => void` | — | 브랜드 영역 클릭 콜백 |

### AI Assistant

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `showAiAssistant` | `boolean` | `true` | AI Assistant 버튼 표시 |
| `aiAssistantLabel` | `string` | `'AI Assistant'` | 버튼 라벨 |
| `onAiAssistantClick` | `() => void` | — | 클릭 콜백 |

### 우측 액션

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `showDownload` | `boolean` | `true` | 다운로드 버튼 |
| `onDownloadClick` | `() => void` | — | 다운로드 클릭 |
| `showNotification` | `boolean` | `true` | 알림 버튼 |
| `notiCount` | `number` | `0` | 1 이상이면 빨간 점 표시 |
| `onNotificationClick` | `() => void` | — | 알림 클릭 |
| `showTheme` | `boolean` | `true` | 테마 버튼 |
| `onThemeClick` | `() => void` | — | 테마 클릭 |
| `showLanguage` | `boolean` | `true` | 언어 버튼 |
| `onLanguageClick` | `() => void` | — | 언어 클릭 |
| `showUser` | `boolean` | `true` | 사용자 버튼 |
| `onUserClick` | `() => void` | — | 사용자 클릭 |
| `showHome` | `boolean` | `true` | 홈 버튼(강조 박스) |
| `onHomeClick` | `() => void` | — | 홈 클릭 |
