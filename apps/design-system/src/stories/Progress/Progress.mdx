<Subtitle>진행률을 시각화하는 컴파운드 바 컴포넌트</Subtitle>

진행률을 시각화하는 바 컴포넌트입니다. `Progress` 단독 사용과 `Progress.Stack` + `Progress.Item` 컴파운드 패턴으로 다중 구간을 표현할 수 있습니다.

<Source code={`import Progress from '@port/design-system'`} language="tsx" />

## API

### Progress

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `number` | — | 0~100 사이의 진행 값 (필수) |
| `color` | `UIColorType` | `'success'` | 색상 — `'success'` \| `'danger'` \| `'warning'` \| `'info'` |
| `shape` | `'linear' \| 'linear-round'` | `'linear-round'` | 바 형태 (모서리 처리) |
| `shadow` | `boolean` | `true` | 배경 그림자(트랙) 표시 여부 |
| `transition` | `boolean \| { duration?, easing? }` | `true` | 애니메이션 설정. false=없음 / true=기본(0.4s ease) / 객체=커스텀 |
| `onComplete` | `() => void` | — | value가 100이 되면 호출되는 콜백 |
| `className` | `string` | — | 루트 요소에 추가할 CSS 클래스 |

### Progress.Stack

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `shape` | `'linear' \| 'linear-round'` | `'linear-round'` | Stack 전체 형태 |
| `shadow` | `boolean` | `true` | 배경 트랙 표시 여부 |
| `children` | `ReactNode` | — | Progress.Item 목록 (필수) |

### Progress.Item

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `value` | `number` | — | 이 구간의 너비 (0~100). 전체 합이 100 초과 시 넘치는 구간은 숨겨집니다. (필수) |
| `color` | `UIColorType` | `'success'` | 이 구간의 색상 |
| `transition` | `boolean \| { duration?, easing? }` | `true` | 구간 개별 애니메이션 설정 |

## Stack — 다중 구간

`Progress.Stack` 안에 `Progress.Item` 을 배치합니다. 각 Item의 value 합이 100을 넘으면 초과분은 표시되지 않습니다.

## Transition

`transition` 옵션으로 애니메이션을 제어합니다. false=없음 / true=기본(0.4s ease) / 객체=커스텀 duration·easing.
