여러 줄 텍스트 입력 컴포넌트입니다. `resize`로 사용자 리사이즈 방향을 제어하고, `height="auto"`로 내용에 따라 높이가 자동으로 늘어나는 동작을 지원합니다.

<Source code={`import Textarea from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `resize` | `CSSProperties['resize']` | `'vertical'` | 사용자가 textarea를 리사이즈할 수 있는 방향 — none, both, horizontal, vertical |
| `height` | `number \| 'auto'` | — | 고정 높이(px) 또는 `'auto'`(내용에 따라 자동 조절) |
| `placeholder` | `string` | — | 빈 상태에서 표시할 힌트 텍스트 |
| `disabled` | `boolean` | — | 입력 비활성화 상태 |
| `className` | `string` | — | 루트 요소에 추가할 CSS 클래스 |
