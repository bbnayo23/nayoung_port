<Subtitle>시작·종료 날짜 범위를 선택하는 컴포넌트</Subtitle>

시작·종료 날짜 범위를 선택하는 컴포넌트입니다. **절대 모드**(날짜 직접 입력·캘린더 선택)와 **상대 모드**(최근 1시간 등 preset, 직접입력 표현식)를 `relativeValue`로 전환합니다. 사이드바의 preset 목록은 `presets` prop으로 완전히 커스터마이즈 가능합니다.

<Source code={`import { RangeCalendar } from '@port/design-system'
import type { RangePreset } from '@port/design-system'`} language="tsx" />

## API

### RangeCalendarProps

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `start` | `Date \| null` | `null` | 선택된 시작 날짜 (controlled) |
| `end` | `Date \| null` | `null` | 선택된 종료 날짜 (controlled) |
| `onStartChange` | `(date: Date) => void` | — | 시작 날짜 변경 핸들러 |
| `onEndChange` | `(date: Date) => void` | — | 종료 날짜 변경 핸들러 |
| `relativeValue` | `string \| null` | `null` | null → absolute 모드 / '' → 직접입력 선택 / preset label → 해당 preset 활성 / 기타 문자열 → 커밋된 표현식 (예: '-7d') |
| `onRelativeValueChange` | `(value: string \| null) => void` | — | relativeValue 변경 핸들러 |
| `presets` | `RangePreset[]` | — (required) | 사이드바에 표시할 preset 목록. preset과 custom 타입을 혼합해 구성합니다. |
| `formatDate` | `(date: Date) => string` | — (required) | Date → 텍스트 변환 함수. input 표시와 동기화에 사용합니다. |
| `parseDate` | `(text: string) => Date \| null` | — (required) | 텍스트 → Date 파싱 함수. 파싱 실패 시 null 반환. |
| `placeholder` | `string` | — | relative 모드 input의 placeholder 텍스트 |
| `disabled` | `boolean` | — | 컴포넌트 전체 비활성화 |
| `disabledBefore` | `Date` | — | 이 날짜 이전은 캘린더에서 선택 불가 |
| `disabledAfter` | `Date` | — | 이 날짜 이후는 캘린더에서 선택 불가 |
| `className` | `string` | — | 루트 wrapper 요소에 추가할 CSS 클래스 |

### RangePreset

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `label` | `string` | — | 사이드바에 표시할 이름. relativeValue의 식별자로도 사용됩니다. |
| `type` | `'preset' \| 'custom'` | — | preset: 클릭 시 getValue()로 범위 적용 / custom: 직접입력 모드 진입 |
| `getValue` | `(now?: Date) => { start, end }` | — | type='preset'일 때 필수. 클릭 시 날짜 범위를 반환합니다. |
| `editValue` | `string` | — | type='preset'일 때 선택. focus 시 input에 prefill할 표현식 (예: '-6h') |

## 절대 모드 (relativeValue=null)

`relativeValue`를 `null`로 유지하면 절대 모드입니다. 시작·종료 날짜 input을 직접 타이핑하거나 달력에서 선택합니다.

<Canvas of={Stories.AbsoluteMode} />

## 상대 모드 (relativeValue 사용)

`relativeValue`에 preset label이나 표현식을 전달하면 상대 모드로 전환됩니다. 사이드바에서 preset을 클릭하거나 직접입력 모드에서 `-6h`, `-7d` 형식으로 입력합니다.

<Canvas of={Stories.RelativeMode} />

## Presets 구성

`presets`는 `type: 'preset'` 항목과 `type: 'custom'` 항목(직접입력)으로 구성합니다. custom은 사이드바 하단에 고정됩니다.

<Canvas of={Stories.WithPresets} />
