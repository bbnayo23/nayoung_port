<Subtitle>날짜·시간 범위를 선택하는 피커 컴포넌트</Subtitle>

날짜·시간 범위를 선택하는 피커 컴포넌트입니다. 프리셋 목록과 캘린더 직접 선택, 텍스트 직접 입력을 모두 지원합니다. `preset` prop으로 제어 모드를, `defaultPreset`으로 비제어 초기값을 설정합니다.

<Source code={`import { DateTimePicker } from '@port/design-system'
import type { DateTimePreset, DateTimeRange } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `label` | `string` | — | 트리거 왼쪽에 표시되는 라벨 |
| `preset` | `DateTimePreset` | — | 제어 모드 프리셋 값 |
| `defaultPreset` | `DateTimePreset` | `'today'` | 비제어 모드 초기 프리셋 |
| `onChange` | `(range: DateTimeRange, preset: DateTimePreset) => void` | — | 날짜 범위 변경 콜백 |
| `presets` | `PresetItem[]` | 기본 10개 | 프리셋 목록 커스터마이즈 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'sm'` | 트리거 크기 |
| `disabled` | `boolean` | `false` | 비활성 상태 |
| `className` | `string` | — | 루트 요소에 추가할 CSS 클래스 |

## Types

<Source code={`type DateTimePreset =
  | 'today' | 'yesterday'
  | 'last30m' | 'last1h' | 'last6h' | 'last12h'
  | 'last1d' | 'last7d' | 'last30d'
  | 'custom'

interface DateTimeRange {
  start: Date
  end: Date
}

interface PresetItem {
  value: DateTimePreset
  label: string
}`} language="tsx" />
