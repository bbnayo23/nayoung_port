EXD 앱 전용 사이드 내비게이션 컴포넌트입니다. 접힘/펼침 상태를 지원하며, 접힌 상태에서 아이콘 위에 마우스를 올리면 Flyout 서브메뉴가 표시됩니다. `menuGroup`은 `MenuItem` 배열을 받으며 중첩 구조를 지원합니다.

import type { SideNavExdProps } from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `menuGroup` | `MenuItem[]` | — | 메뉴 그룹 데이터. MenuItem은 children으로 서브메뉴를 가질 수 있습니다. |
| `activeKey` | `string` | — | 현재 활성화된 메뉴 아이템의 key |
| `onActiveChange` | `(key: string) => void` | — | 활성 메뉴 변경 콜백 |
| `collapsed` | `boolean` | `false` | 접힌 상태. true 시 아이콘만 표시. |
| `onCollapse` | `(collapsed: boolean) => void` | — | 접힘/펼침 변경 콜백 |
| `hidden` | `boolean` | `false` | 숨김 상태 |
| `onHidden` | `(hidden: boolean) => void` | — | 숨김 상태 변경 콜백 |
| `header` | `ReactNode` | — | 사이드 내비게이션 상단 헤더 슬롯 |
| `aiChatSlot` | `ReactNode` | — | AI 채팅 버튼 슬롯 (하단 영역) |

### MenuItem

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `key` | `string` | — | 고유 키 (필수) |
| `label` | `string` | — | 메뉴 레이블 (필수) |
| `icon` | `ReactNode` | — | 메뉴 아이콘 (@port/icon-library 사용 권장) |
| `children` | `MenuItem[]` | — | 서브 메뉴. 있으면 펼침/접힘 가능한 그룹으로 렌더됩니다. |
| `badge` | `number` | — | 알림 배지 숫자. 99 초과 시 '99+' 표시. |
| `type` | `'item' \| 'group'` | `'item'` | 'group' 설정 시 클릭 불가한 섹션 레이블로 렌더됩니다. |
