## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `checked` | `boolean` | `false` | 체크 상태 |
| `indeterminate` | `boolean` | `false` | 중간(mixed) 상태 — checked와 독립적으로 동작 |
| `disabled` | `boolean` | `false` | 비활성화 — opacity 0.5, cursor not-allowed |
| `label` | `string \| ReactNode` | — | 체크박스 옆에 표시할 라벨 |
| `labelDirection` | `'left' \| 'right'` | `'right'` | 라벨 위치 |
| `color` | `'danger' \| 'warning' \| 'success' \| 'info'` | — | 체크 색상 variant |
| `onChange` | `(e: ChangeEvent) => void` | — | 상태 변경 핸들러 |
| `id` | `string` | — | label htmlFor 연결용 id |
