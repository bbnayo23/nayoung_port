<Subtitle>카테고리별 다중 선택을 지원하는 사이드 필터 패널</Subtitle>

카테고리별 다중 선택을 지원하는 사이드 필터 패널입니다. `Filter.Search` · `Filter.Content` · `Filter.SelectAll` · `Filter.Categories` 컴파운드 패턴으로 구성하며 접기/펼치기가 가능합니다. `groups` prop을 전달하면 내부에서 Accordion·Checkbox를 자동으로 렌더링하는 데이터 주도 방식도 지원합니다.

<Source code={`import Filter from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `title` | `string` | `'필터'` | 필터 패널 상단 타이틀 |
| `collapsed` | `boolean` | `false` | 접힌 상태 여부 (controlled) |
| `onCollapse` | `() => void` | — | 접기 버튼 클릭 시 호출되는 콜백 (required) |
| `children` | `ReactNode` | — | Filter.Search · Filter.Content 등 서브 컴포넌트 |
| `className` | `string` | — | 루트 래퍼에 추가할 CSS 클래스 |

### 서브 컴포넌트

| 컴포넌트 | 역할 |
| --- | --- |
| `Filter.Search` | 검색 입력 영역 (SearchBar 등 배치) |
| `Filter.Content` | 필터 본문 래퍼 — SelectAll · Categories를 감쌉니다 |
| `Filter.SelectAll` | 전체 선택 체크박스 영역 |
| `Filter.Categories` | 카테고리 목록 스크롤 영역 |

## 기본 사용

검색 · 전체 선택 · Accordion 카테고리 체크박스가 모두 연동되는 인터랙티브 예제입니다. `Filter.Search`에 검색 입력을, `Filter.Content > Filter.SelectAll`에 전체 선택 체크박스를, `Filter.Categories`에 카테고리 목록을 배치합니다.

## 데이터 주도 방식

`groups` prop을 전달하면 Filter가 내부에서 Accordion·Checkbox를 자동으로 렌더링합니다. `selected` · `onChange` · `searchValue` · `expandedIds` 등으로 상태를 제어합니다.

## 상태 (펼침 / 접힘)

`collapsed`로 펼친 상태와 접힌 상태를 제어합니다. 접힌 상태에서는 외부 버튼으로 다시 펼칠 수 있습니다.
