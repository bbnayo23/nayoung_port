현재 페이지의 위치를 계층적으로 표시하는 네비게이션 컴포넌트입니다. 구분자 커스터마이즈와 긴 경로 축약(maxItems)을 지원합니다.

<Source code={`import Breadcrumbs from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `separator` | `string \| ReactNode` | `'›'` | 항목 사이에 표시할 구분자. 문자열 또는 ReactNode 모두 가능합니다. |
| `maxItems` | `number` | `0` | 최대 표시 항목 수. 초과 시 중간 항목을 ⋯ 버튼으로 축약합니다. 0이면 전체를 표시합니다. |
| `children` | `ReactNode` | — | 브레드크럼 항목. 일반적으로 `<a>`, `<span>`, `<button>`을 사용합니다. |
| `className` | `string` | — | `<nav>` 요소에 추가할 CSS 클래스 |
| `style` | `CSSProperties` | — | `<nav>` 요소에 적용할 인라인 스타일 |
