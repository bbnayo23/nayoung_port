## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `nodes` | `TreeNode[]` | — | 트리 노드 데이터 배열. 각 노드는 id, label, children?, disabled? 를 가집니다. |
| `expandedIds` | `string[]` | — | 현재 펼쳐진 노드 id 목록 (controlled). 미전달 시 내부 상태로 관리됩니다. |
| `onExpandChange` | `(ids: string[]) => void` | — | 펼치기/접기 변경 핸들러 |
| `selectedId` | `string` | — | 현재 선택된 노드 id (controlled) |
| `onSelect` | `(id: string) => void` | — | 노드 선택 핸들러 |
| `className` | `string` | — | 루트 ul 요소에 추가할 CSS 클래스 |

### TreeNode

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `id` | `string` | — | 노드 고유 식별자 |
| `label` | `ReactNode` | — | 노드 표시 텍스트 또는 JSX |
| `children` | `TreeNode[]` | — | 하위 노드 배열. 있으면 펼치기 아이콘 표시 |
| `disabled` | `boolean` | — | 비활성화 — 클릭 불가, 시각적으로 흐리게 표시 |
