## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `selected` | `Date \| undefined` | — | 현재 선택된 날짜 |
| `onSelect` | `(date: Date \| undefined) => void` | — | 날짜 선택 시 호출되는 콜백 |
| `disabledBefore` | `Date` | — | 이 날짜 이전은 선택 불가 |
| `disabledAfter` | `Date` | — | 이 날짜 이후는 선택 불가 |
| `className` | `string` | — | 최상위 wrapper에 추가할 className |
