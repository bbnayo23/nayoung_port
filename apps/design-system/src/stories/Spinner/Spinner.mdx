<Subtitle>비동기 작업 진행 중임을 나타내는 로딩 인디케이터</Subtitle>

비동기 작업 진행 중임을 나타내는 로딩 인디케이터입니다. `type`으로 외형을 선택하고, `size`로 크기를 조정합니다. `overlay`를 사용하면 컨텐츠 위를 덮어 로딩 상태를 표시할 수 있습니다.

<Source code={`import Spinner from '@port/design-system'`} language="tsx" />

## API

| Prop | Type | Default | 설명 |
| --- | --- | --- | --- |
| `type` | `'default' \| 'dots' \| 'outline'` | `'default'` | 스피너 유형. default(테두리), dots(점), outline(그라데이션 테두리) |
| `variant` | `'solid' \| 'round' \| 'circle' \| 'outline' \| 'flow' \| 'bounce' \| 'fadeinout'` | — | type을 오버라이드하는 세부 variant |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 스피너 크기 — sm(24px), md(36px), lg(48px) |
| `color` | `string` | — | CSS 색상값으로 스피너 색상을 직접 지정. 미설정 시 primary 색상 사용 |
| `overlay` | `boolean` | `false` | true이면 부모 영역을 반투명 레이어로 덮어 전체 로딩 상태 표시 |
| `className` | `string` | — | 루트 wrapper 요소에 추가할 CSS 클래스 |

## Type

`variant`를 지정하지 않으면 `type`에 따라 기본 variant가 결정됩니다. 모든 type과 size의 조합을 매트릭스로 확인합니다.

<Canvas of={Stories.TypeSizeMatrix} />

## Variant × Size 매트릭스

`variant` prop으로 외형을 직접 지정합니다. 모든 variant와 size의 조합 매트릭스입니다.

## Overlay

`overlay=true`로 부모 영역을 반투명 레이어로 덮어 전체 로딩 상태를 표시합니다. 부모에 `position: relative`가 필요합니다.

<Canvas of={Stories.Overlay} />

## 커스텀 색상

`color` prop으로 스피너 색상을 직접 지정합니다. CSS 색상값을 모두 지원합니다.
